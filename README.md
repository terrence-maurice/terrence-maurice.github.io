# Tereza Muric — portfolio

Statický web pro GitHub Pages (bez build kroku).

- `index.html` — kostra stránky
- `assets/content.js` — **veškerý obsah** (texty CZ/EN, seznam videí, galerií a zvuků). Nová díla se přidávají sem.
- `assets/app.js` — navigace, přepínání jazyka, galerie (klik = další obrázek, swipe na mobilu)
- `assets/sparkle.js` — jiskřivé pozadí reagující na scrollování
- `assets/style.css` — vzhled
- `media/` — webově zkomprimovaná videa (H.264 720p), obrázky (WebP) a zvuky

GitHub omezuje velikost souboru na 100 MB a celý web na ~1 GB, proto jsou videa zmenšená. Originály zůstávají v nadřazené složce.
